ТВОРИВО — статичний сайт

Каталог зберігається у файлі:
  data/products.js

Кожен товар має поля:
  id        — унікальний ідентифікатор
  name      — назва товару
  category  — категорія; фільтр створюється автоматично
  image     — шлях до зображення
  details   — довільний багаторядковий текст: розміри, вага, ціни, примітки тощо
  featured  — true, якщо товар треба показувати на головній

Приклад details:
  "45 × 50 см\n71 кг\nСіра: 2 100 грн\nКолір: 2 800 грн"

Каталог не використовує fetch(), тому сайт працює і при відкритті локально без CORS.

ГАЛЕРЕЯ ВИКОНАНИХ РОБІТ
------------------------
Медіафайли лежать у папці gallery/. Сторінка: gallery.html.
Фото і відео відображаються без підписів та відкриваються у повноекранному перегляді.

Якщо локальний вебсервер показує список файлів папки, галерея підхоплює нові файли автоматично.
Якщо сервер не віддає список папки, після додавання/видалення файлів запустіть update-gallery.bat — він оновить data/gallery.js.
Підтримувані фото: jpg, jpeg, png, webp, gif, avif.
Підтримувані відео: mp4, webm, mov, m4v, ogv (відтворення залежить від кодека браузера).
